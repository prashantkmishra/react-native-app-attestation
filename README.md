# react-native-app-attestation

React Native library for mobile app integrity and attestation using Android Play Integrity API and iOS App Attest.

## Installation


```sh
npm install react-native-app-attestation
```


## Usage


```js
import { multiply } from 'react-native-app-attestation';

// ...

const result = multiply(3, 7);
```
